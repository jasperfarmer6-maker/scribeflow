# 已知问题

> 文档状态：已验证事实/待验证项混合｜最后验证：2026-08-01

- 厚文档可能触发 MinerU 工作服务内存压力；程序会按页数降低处理窗口，但仍可能需要关闭其它高内存应用或拆分 PDF。
- 首次运行可能下载 OCR 模型，耗时和网络要求取决于模型源。
- MinerU 失败、超时或返回 502 时会保留已完成分段；使用相同输入、输出目录和 `--resume` 可跳过已完成分段，但失败的单段仍需重新 OCR。
- 应用层分段会在段边界切断跨页版面；正文页码可连续合并，但跨段复杂表格和特殊版面仍需人工复核。
- 某些 OpenAI 兼容服务不支持 `response_format`，程序会回退兼容模式；这会降低协议约束强度。
- 复杂表格、跨页版面、低质量扫描和特殊字体需要人工复核。
- 当前 App 构建目标为 Apple Silicon；其它架构属于待验证项。
- SwiftUI App 构建需要完整 Xcode；仅安装 CommandLineTools 时缺少 `SwiftUIMacros`，无法编译 GUI。
