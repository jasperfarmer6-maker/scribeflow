# 能力边界

> 文档状态：已验证事实｜最后验证：2026-08-01

## 支持

- macOS 本地扫描版 PDF OCR。
- 标题、正文、表格、公式、图片和章节 Markdown 输出。
- 确定性清洗、可选 AI 块级清洗、审计记录和失败现场保留。
- CLI 与 macOS GUI 两种入口。
- 300–500 页目标规模的串行分段 OCR、checkpoint 和失败后续跑。

## 不保证

- 复杂双栏、手写体、严重倾斜或低清扫描件的完美阅读顺序。
- 复杂跨页表格、特殊字体和所有公式的完美还原。
- AI 服务可用性、模型输出质量或 MinerU 上游内部行为。
- OCR 模型缓存路径在所有 MinerU 版本中都可被本项目读取。

最终内容应对关键页人工抽查。
